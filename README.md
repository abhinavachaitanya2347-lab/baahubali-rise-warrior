# Kalki: Desert Run

An unofficial sci-fi fantasy endless runner fan game built with plain HTML, CSS and JavaScript. Supports desktop and mobile browsers. No build tools or dependencies are required.

## Run locally
1. Download and unzip this project.
2. Open `index.html` in Chrome, Edge, Firefox or Safari.

## Controls
- Jump: Space, Arrow Up, or W
- Slide: Arrow Down or S
- Pause/resume: P, Escape, or the pause button
- Mobile: use the on-screen Jump and Slide buttons, or tap the game area to jump.

## Features
- Original canvas-drawn sci-fi fantasy warrior
- Endless runner with increasing speed
- Ruin/debris and overhead gate obstacles
- Collectible energy cores
- Distance score and saved personal best
- Browser-generated sound effects
- Responsive mobile and desktop layout

## Deploy to GitHub and Vercel
1. Create a GitHub repository, e.g. `kalki-desert-run`.
2. Upload `index.html`, `style.css`, `game.js`, and `README.md` to its root.
3. Sign in to https://vercel.com/ with GitHub.
4. Choose **Add New → Project** and import the repository.
5. Select **Other** as the framework preset. Leave Build Command empty; use `.` as Output Directory if prompted.
6. Click **Deploy**. Vercel provides a public URL and can redeploy on future GitHub pushes.
